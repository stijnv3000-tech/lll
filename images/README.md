# Portfolio screenshots

Plaats hier de echte homepage-screenshots. De portfolio-tegels gebruiken deze
bestanden automatisch (via de `--shot` CSS-variabele in `index.html`). Zolang een
bestand ontbreekt, valt de tegel netjes terug op een merk-gradient.

Verwachte bestandsnamen (exact):

| Bestand                   | Project              | Live site               |
|---------------------------|----------------------|-------------------------|
| `simonta.jpg`             | Simonta              | simonta.eu              |
| `mergelgrotten.jpg`       | Mergelgrotten Zichen | mergelgrottenzichen.be  |
| `tuinwerken.jpg`          | Tuinwerken Stas      | tuinwerkenstas.be       |
| `fadim.jpg`               | Fadim Official       | fadimofficial.be        |

Aanbevolen: liggend, ~1200×900px (of 16:10), de bovenkant van de homepagina in beeld.
`.jpg` of `.webp` (pas dan de extensie in `index.html` aan).
